TornPulse Emoji Pack Upload Instructions

1) Download this ZIP to your phone.
2) Extract it.
3) Upload ONLY the file named:
   patch-v100-hud.cjs
   into the MAIN / ROOT folder of your comfortable-ai repo.
4) Replace the existing file with the same name.
5) Commit the change.
6) Wait 1-2 minutes for GitHub Actions to build.
7) Come back and say: Check

You do NOT need to touch main.yml.
You do NOT need to re-upload the header image.
This patch keeps the exact top header/logo from the successful build and adds emoji replacements for:
Health, Energy, Nerve, Torn Time, Drug, Booster, Medical, Scanner, and Targets.
