TORNPULSE HUD 2.0 VISUAL REBUILD — HUD201

This is a visual-only native HUD rebuild on top of the successful Torn Pulse 2.0 shell.

What changed:
- Slim 44dp collapsed TP rail remains.
- Expanded HUD is a compact blue/cyan right-side panel.
- 2x2 vitals grid: Health, Energy, Nerve, Happiness.
- Torn Time gets a blue/cyan digital TCT card.
- Drug/Booster/Medical are compact cooldown tiles.
- Baldr's List remains a user-tapped external link only.
- Activity/status line remains read-only.
- Red is reserved for hospital/attack/danger states.
- Existing API polling, notifications, docking, drag/lock, collapse, permissions, and compliance behavior are preserved.

INSTALL FROM PHONE:
1. Download app.config.js from this package.
2. In GitHub repo realsmyreligion/comfortable-ai, use Add file > Upload files.
3. Upload this app.config.js at the repository root, replacing the existing app.config.js.
4. Commit directly to main.
5. The existing Build TornPulse 2.0 workflow should run automatically.

No other source file needs to be changed for this HUD preview.
